Projeto de **Pensamento Computacional** em que os estudantes constroem, passo a passo, um pequeno **recomendador de filmes** em JavaScript, a partir de regras de idade e preferência de gênero.

A proposta conecta **conceitos básicos de programação** com um exemplo concreto e próximo da realidade dos alunos: escolher filmes a partir de critérios bem definidos.

---

## Objetivos de aprendizagem

- Trabalhar o conceito de **funções** em JavaScript (entrada, processamento, saída).
- Praticar **estruturas condicionais** (`if/else`, operadores lógicos).
- Modelar um **fluxo de decisão** (faixa etária × categoria de filme).
- Reforçar a ideia de **algoritmo** como sequência de passos bem definida.
- Integrar **HTML + CSS + JavaScript** em uma página simples, mas funcional.

---

## Conteúdos de programação trabalhados

- **JavaScript**
  - Declaração e chamada de funções.
  - Parâmetros e retorno.
  - Condicionais encadeadas (`if / else if / else`).
  - Operadores lógicos (`&&`, `||`, `!`).
- **Lógica**
  - Tradução de regras em **tabela de decisão** e fluxograma.
  - Mapeamento de regras de negócio para código.
- **Front-end básico**
  - Formulário HTML para entrada de dados (idade, gênero, etc.).
  - Exibição da recomendação na própria página.
  - Estilização simples com CSS para torná-la utilizável em sala.

---

## Estrutura do projeto

O repositório organiza os materiais em:

- **`/src` ou pasta principal**  
  Código JavaScript com as funções de recomendação (regra de negócio).
- **Arquivos HTML/CSS**  
  Interface mínima para interação com o usuário (inputs + botão + resultado).
- **Materiais de apoio** (quando aplicável)  
  Roteiro de atividade, enunciado e orientações para alunos.

Recomendação típica de fluxo em sala:

1. Discutir com a turma **quais critérios** fazem sentido para recomendar filmes.
2. Montar, junto com os alunos, um **fluxograma** ou tabela de decisão.
3. Implementar as regras primeiro em pseudocódigo, depois em JavaScript.
4. Conectar a função de recomendação à interface HTML.
5. Explorar casos de teste (idades e gêneros diferentes) e discutir resultados.
